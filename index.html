Java ASM Compiler

OLYMPUS Compiler

A custom compiler built in Java that translates OLYMPUS source code into MIPS assembly language for simulation in tools like MARS.

The compiler features a multi-stage frontend with a scanner, parser, and semantic analyzer that translates code into three-address intermediate code (TAC) and final MIPS assembly. For memory efficiency, it implements dynamic stack frame management using $sp and $fp, variable compaction (packing consecutive 1-byte chars and booleans), and dynamic padding to maintain 4-byte alignment for integers while adapting MIPS load/store word and byte instructions.

C IPC Networking Threads

La Ciutadela

A multi-process and multi-threaded system simulation in C simulating communicating medieval kingdoms. Focuses on low-level systems programming and inter-process communication (IPC).

The system models a main process coordinated with multiple background threads and messenger child processes spawned via fork. It uses POSIX sockets for cross-machine kingdom networking, anonymous pipes for parent-child IPC, semaphores and mutexes for synchronization, and select-driven non-blocking IO with timeout recovery.

C Java Embedded PWM

LSFarm

An embedded farm simulation system (LSFarm) built in C for PIC microcontrollers, controlled via an interactive Joystick and a host Java GUI interface.

The firmware features a cooperative state machine architecture to optimize PIC resources (100% Flash, 97% RAM). It handles multi-channel ADC inputs (Joystick X/Y and LDR light sensor for animal sleep mechanics), custom software UART channels for serial communication with the Java host, and dynamic LCD notifications, with persistent state storage on EEPROM.
